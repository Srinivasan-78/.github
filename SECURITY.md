# Security Policy

## Reporting a vulnerability

Please report security issues **privately**. Do not open a public issue.

- Preferred: open a private report via the repository's **Security → Advisories → Report a vulnerability**.
- Or email: srinivasan.shyam2000@gmail.com

Include the affected repo, a description, reproduction steps, and impact.

You can expect an acknowledgement within **72 hours** and an update on next steps
once the report has been triaged.

## Supported versions

Unless a repo states otherwise, only the latest release / default branch is
supported with fixes.
