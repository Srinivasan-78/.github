# .github

Account-wide community health defaults for [@Srinivasan-78](https://github.com/Srinivasan-78).

GitHub applies the files below to **every** repository in this account that does
not provide its own copy — so issue forms, the PR template, the code of conduct,
security policy and support info stay consistent without being duplicated into
each repo.

| File | Applies when a repo lacks its own |
|---|---|
| `.github/ISSUE_TEMPLATE/` | Bug / feature issue forms + config |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default PR description |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1 |
| `CONTRIBUTING.md` | How to contribute |
| `SECURITY.md` | How to report a vulnerability |
| `SUPPORT.md` | Where to get help |

`CODEOWNERS` and `dependabot.yml` are **not** inheritable — they live in each repo.
